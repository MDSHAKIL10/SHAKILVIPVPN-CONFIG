Publish configurations

Creates a public, credential-free JSON configuration document. The mobile app fetches the published file automatically and on manual refresh. A GitHub token with contents-write access is required only for publishing; use a narrowly scoped fine-grained token and do not share this browser profile. This static Pages/raw-content endpoint is a read API, not an authenticated server-side API.

Server configurations

Protocol compatibility

VLESS/Xray configurations are supported by the Android client. UDP/Hysteria entries can be authored and published as typed data, but the current app intentionally rejects them because no Hysteria engine is integrated. TLS and WebSocket options are kept separate from UDP fields. Never include a server UUID, password, private key, or authentication token in this public file.
